# خالد النجم الطائر - Android build

هذا المجلد مخصص لنسخة لعبة خالد. بعد إضافة ملف `KhaledStarHero-source.zip` إلى هذا المجلد، يبدأ GitHub Actions بناء APK تلقائيًا ويرفعه كـ Artifact باسم `KhaledStarHero-Android-APK`.

ملف المصدر لا يحتوي على مفتاح توقيع خاص. ينتج البناء نسخة Debug قابلة للتثبيت للاستخدام الشخصي.
